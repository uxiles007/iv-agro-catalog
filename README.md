# IV-AGRO Catalog

Публічні довідникові дані для автоматичного оновлення застосунку IV-AGRO.

Цей репозиторій не містить вихідного коду застосунку, фотографій, профілів, полів або історії робіт користувачів.

## Файли

- `seed-register.json` — державний реєстр і перевірені каталоги посівмату.
- `sunflower-catalog.json` — довідник технологій соняшнику.
- `agrochemistry-catalog.json` — каталог агрохімії.
- `agrochemistry-adjuvants.json` — додатковий довідник прилипачів.
- `catalog-provenance.json` — джерела та дати перевірки.
- `manifest.json` — версія, розмір і SHA-256 кожного файла.

Довідкова інформація не замінює етикетку препарату, офіційний регламент застосування та консультацію кваліфікованого агронома.
